# Color Piano

Masomenos Lab is a project initiated by [masomenos](https://masomenos.fr/) with the aim to explore the symbiosis between music, video, light and live performance through the development of interactive artworks.

The Color Piano is a public art installation which was exhibited in a street of Paris during about 1 year as the first digital creation by Masomenos Lab. It invited the pedestrians to interact with the piece by playing with live music and visual compositions.

The software is a custom Processing application that takes live cues from Ableton Live so that each pitch triggers a visual reaction via the MIDI protocol, hence allowing the user to compose audiovisual environments in real time.

The same tool can be used for both interactive installations and live performances. It was showcased at the residency of masomenos at Badaboum nightclub in Paris and on March 12, 2014 at the London Electronic Orchestra, an event produced by Kate Simko.
