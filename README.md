# aurelienkrieger.com

Personal portfolio built from Markdown with Quartz 5.

## Development

```bash
npm install
npx quartz build --serve
```

Content lives in `content/`. Project pages live in `content/work/`; site assets live in `content/assets/`.

The visual identity is implemented in `quartz/styles/custom.scss`, with the site header in `quartz/components/Header.tsx`.
